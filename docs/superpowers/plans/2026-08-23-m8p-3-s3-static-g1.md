# M8P-3 Constrained S3 Alignment and Static G1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert a validated S2 selection into a canonical, bounded S3 draft and publish one atomic bundle only after deterministic static G1 passes.

**Architecture:** The model proposes edits only; it never emits resume structure, a change log, or a document. Code revalidates the complete M8P artifact chain, derives a privacy-minimised alignment view from the current master profile, applies strictly bounded edits, derives the diff/change log, and runs a typed static G1 aggregate before publication.

**Tech Stack:** Python 3.11+, frozen dataclasses, stdlib `json`/`hashlib`/`difflib`, existing PyYAML profile loader, existing safe Claude subprocess wrapper, pytest.

**Spec:** `docs/superpowers/specs/2026-08-23-m8p-3-s3-static-g1-design.md`
