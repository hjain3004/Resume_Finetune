# M8P-2 JD-Only Positioning and Structural Selection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a safe, one-job-at-a-time S0 positioning stage and S2 structural-selection stage that turn a validated M8P-1 `s1.json` into a deterministically validated `s2.json`, without generating resume prose or mutating the database.

**Architecture:** Build two privacy-minimised projections from `MasterProfile`, then pass strict file contracts through two tool-disabled model calls. S0 produces a 2–4-point JD-anchored strategy; S2 sees only identifiers/tags/priorities and produces a base variant, project/bullet selection, and complete must-have coverage table. Pure parsers and deterministic semantic/selection validators sit before every artifact publication boundary.

**Tech Stack:** Python 3.11+, frozen dataclasses, standard-library `json`/`subprocess`/`tempfile`, existing PyYAML profile loader, existing `src.llm_trace.write_trace`, pytest. No new dependency.

**Spec:** `docs/superpowers/specs/2026-08-23-m8p-2-s0-s2-design.md` (also governed by `docs/TAILORING_METHODOLOGY.md` §3 and `docs/superpowers/specs/2026-08-21-m8-human-pilot-s1-design.md`)
